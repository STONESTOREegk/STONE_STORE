# STONE STORE

Оригинальная одежда известных брендов в Егорьевска.

## О проекте

STONE STORE — это онлайн-магазин оригинальной одежды премиум-класса, спеалирующий на эксклюзивных брендах, в первую очередь **Stone Island**. Магазин работает через Telegram-канал.

## Ссылка

[Telegram канал @stonestoreegk](https://t.me/stonestoreegk)

## Запуск

Этот лендинг размещён через **GitHub Pages** и доступен по адресу вашего репозитория.

## Структура файлов

```
stone-store/
├── index.html      — основной HTML-файл
├── style.css       — стили CSS (тёмная тема с зелёными акцентами)
├── script.js       — минимальный JavaScript (плавный скролл + мобильное меню)
├── assets/
│   └── qrcod.png  — QR-код для входа в Telegram канал
└── README.md
```

## Технологии

- **HTML5** — семантичная разметка
- **CSS3** — чистый CSS с адаптивным дизайном
- **Vanilla JavaScript** — без фреймворков
- **Google Fonts** — шрифт Inter
- **SVG** — лёгкие векторные изображения

## Функционал

- Плавная прокрутка по секциям
- Мобильное меню (бургер-меню)
- Анимации при скролле
- Адаптивный дизайн для всех устройств
- QR-код для быстрого доступа в Telegram

## Цветовая схема

- **Основной цвет:** тёмный (#0a0a0a)
- **Акцентный цвет:** глубокий зелёный (#2d5f2e)
- **Фоновый текст:** светло-серый (#d0d0d0)
